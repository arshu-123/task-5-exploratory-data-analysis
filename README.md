# Task 5 - Exploratory Data Analysis (EDA)

## Project Title

Netflix Movies and TV Shows Exploratory Data Analysis

## Objective

Perform Exploratory Data Analysis to discover trends, patterns, and insights from Netflix content data.

## Dataset Used

Netflix Movies and TV Shows Dataset

## Tools Used

* Python
* Pandas
* Matplotlib
* Seaborn
* Jupyter Notebook

## Analysis Performed

* Dataset overview using info() and describe()
* Missing value analysis
* Content type distribution
* Release year analysis
* Country-wise content analysis
* Rating distribution analysis
* Correlation heatmap

## Visualizations

* Movies vs TV Shows Distribution
* Release Year Distribution
* Top Countries by Content
* Content Rating Distribution
* Correlation Heatmap

## Key Insights

* Movies dominate Netflix content.
* Content production increased significantly after 2015.
* The United States contributes the highest number of titles.
* TV-MA and TV-14 are common ratings.
* Netflix has expanded content rapidly in recent years.

## Outcome

Successfully explored and analyzed Netflix content data to identify trends and support data-driven decision-making.
